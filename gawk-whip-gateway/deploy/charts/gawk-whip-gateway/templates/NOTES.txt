OBS users enter, in Settings → Stream (Service: WHIP):
  Server:       https://{{ $host }}/whip
  Bearer Token: the gawk1_… key the web app's OBS page creates
The frontend chart's config.whipGatewayUrl must be https://{{ $host }},

Requirements (docs/83 D4, D10, D12; docs/self-hosting.md):

1. The relay: publishProxy.token (or tokenSecretRef) equal to
   relay.publishProxyToken here, and an explicit config.resumeTokenKey.
   Setting the key on a relay that had none revokes every resume token in
   use, once.

2. Every request for a key must reach the pod holding its session (D10).
{{- if .Values.httpRoute.enabled }}
{{- if eq .Values.httpRoute.keyHash "envoy-gateway" }}
   The HTTPRoute's BackendTrafficPolicy hashes on Authorization (Envoy
   Gateway). Check that it is Accepted:
   kubectl get backendtrafficpolicy {{ $full }} -o jsonpath='{.status}'
{{- else }}
   httpRoute.keyHash is none, which holds only at replicas: 1.
{{- end }}
   The Gateway needs an HTTPS listener for the WHIP host that allows this
   namespace's routes.
{{- else if .Values.ingress.enabled }}
   The Ingress hashes on Authorization through
   nginx.ingress.kubernetes.io/upstream-hash-by: "$http_authorization";
   ingress-nginx is the only Ingress controller supported.
{{- else }}
   Neither httpRoute nor ingress is enabled: route the WHIP host to Service
   {{ $full }} with a hash on the Authorization header yourself, or keep
   replicas: 1.
{{- end }}

3. trustedProxyCidrs (now: {{ if .Values.trustedProxyCidrs }}{{ join ", " .Values.trustedProxyCidrs }}{{ else }}empty{{ end }}) lists ONLY the proxy
   that writes X-Forwarded-For: the Gateway's proxy pods or the ingress
   controller's pod range, or under hostNetwork its exact node addresses
   (/32, /128). Never a subnet
   clients share, never a kube-proxy SNAT hop in front of it; both families
   on dual-stack. The proxy must see real client IPs
   (externalTrafficPolicy: Local on its Service, or PROXY protocol).
{{- if and (or .Values.ingress.enabled .Values.httpRoute.enabled) (not .Values.trustedProxyCidrs) }}
   WARNING: a route is enabled and trustedProxyCidrs is empty, so
   every OBS user shares ONE rate-limit bucket on the gateway and on the
   relay.
{{- end }}

4. The firewall (and any NAT in front of the LoadBalancer) must pass
   {{ if .Values.publicAddress }}{{ .Values.publicAddress }}{{ else }}publicAddress{{ end }} ports {{ $base }}-{{ $last }}, UDP and TCP: pod N's media is on
   {{ $base }} + N, through Service {{ $full }}-media-N.

5. Capacity: maxSessions ({{ .Values.maxSessions }}) is per pod. Keys hash unevenly, so
   {{ .Values.replicas }} × {{ .Values.maxSessions }} holds only on average, and only
   ({{ .Values.replicas }} − 1) × {{ .Values.maxSessions }} = {{ mul (sub (int .Values.replicas) 1) (int .Values.maxSessions) }} sessions are safe through a pod
   restart. The defaults and resource requests are provisional until WG0.
