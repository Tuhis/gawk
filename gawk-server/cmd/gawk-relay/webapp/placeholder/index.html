No web app in this build

This gawk-relay was built from a tree without a staged gawk-app build, so it has no broadcaster or viewer page to serve. The relay itself works: browsers and the native apps can still use it.

Release binaries and the container image include the app. To include it in a local build, run gawk-server/cmd/gawk-relay/webapp/stage.sh before go build ./cmd/gawk-relay.
