# Third-party notices — `gawk-ios`

The gawk iOS app. Everything listed here is in its Rust core
(`gawk-core`), the one static library the app links; the app and its
Live Activity add no third-party code of their own.

**libopus** is compiled in statically through `audiopus_sys` (ISC for
the bindings, Xiph's BSD-3-Clause for the C library, listed as
`libopus`), and **libvpx** through `shiguredo_libvpx`, which builds it
from upstream source (Apache-2.0 for the bindings, the WebM Project's
BSD-3-Clause and patent grant for the library, listed as `libvpx`).
The **uniffi** crates are under the Mozilla Public License 2.0; where
to get their source is under *Source code* below. The Apple
frameworks the app links (ScreenCaptureKit, VideoToolbox, SwiftUI and
the rest) are part of iOS and are governed by Apple's terms, not by
anything here.

This file is generated. Do not edit it by hand — run
`python3 tools/licenses/gen-notices.py` and commit the result. See that
script for what counts as a dependency here and why.

**Scope:** `cargo tree -e normal --target aarch64-apple-ios -p gawk-core` — build- and dev-dependencies (proc macros, the UniFFI bindgen, test harnesses) are excluded because they are not part of the shipped app.
